FLOPs are TensorFlow graph float operations for batch size 1; MACs are estimated as FLOPs/2. Latency excludes data loading and uses synchronized batch-1 GPU forward passes after warm-up. TensorFlow GPU memory is allocator current/peak memory measured after warm-up, not total board VRAM. FLOPs/storage and GPU runtime were measured in separate fresh Python interpreters. Cross-model deployment plots are valid only when every baseline is re-profiled with this same script, hardware, and software environment.
